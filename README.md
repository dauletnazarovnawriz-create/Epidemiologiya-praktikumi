# Epidemiologik praktikum / Эпидемиологический практикум

Интерактивный учебный тренажёр по эпидемиологии и военной эпидемиологии для студентов-медиков (лечебное дело, 5 курс). Интерфейс и учебный материал на узбекском языке (латиница). Весь проект — **один HTML-файл** без внешних зависимостей: открывается в браузере двойным щелчком, работает офлайн.

> **Epidemiologik praktikum** — Epidemiologiya va Harbiy epidemiologiya fanlari bo'yicha interaktiv amaliy trenajyor. Mavzular kafedraning kalendar-tematik rejasiga (2026–2027 o'quv yili) muvofiq tartiblangan.

---

## Возможности

| Раздел | Что внутри |
|---|---|
| **Vazifalar** | 10 расчётных задач по эпидемиологическим показателям (заболеваемость, распространённость, атрибутивная доля, OR, PPV, NPV, CFR, CAGR, индекс эффективности вакцины K, вторичная заболеваемость). Числа генерируются заново при каждом запуске, есть подсказки и разбор решения. |
| **Kasallik o'chog'i** | 27 интерактивных сценариев эпидемических очагов в форме чата (запросы о диагнозе, эпидемической кривой, больных, лаборатории, мерах) + по 10 вопросов на каждый очаг. Очаги сгруппированы по темам практических занятий. |
| **Vaziyatli masalalar** | 11 тематических блоков по 10 вопросов: методы исследований, скрининг, иммунизация, внутрибольничные инфекции и **7 блоков по Национальному календарю профилактических прививок Узбекистана**. |
| **AI-yordamchi** | Справочный помощник по формулам и терминам (правила на ключевых словах, не языковая модель). |
| **Hisobot** | Личный отчёт участника: история попыток, средние результаты, выгрузка в CSV. |
| **Lug'at** | Глоссарий терминов. |

### Очаги по группам (порядок соответствует практическим занятиям)

1. Дезинфекция, дезинсекция, дератизация, стерилизация
2. Кишечные инфекции: сальмонеллёз, шигеллёз, брюшной тиф и паратиф
3. Дыхательные инфекции: грипп, корь, дифтерия, коклюш, паротит, скарлатина, менингококковая инфекция, COVID-19
4. Вирусные гепатиты, ВИЧ/СПИД и парентеральные инфекции: гепатит B, ВИЧ, бешенство (zoonoz parenteral)
5. Сапронозы и паразитарные болезни: легионеллёз, столбняк, малярия, гельминтозы
6. Карантинные и особо опасные инфекции: холера, чума, сибирская язва, ККГЛ, туляремия
7. Военная эпидемиология: брюшной тиф в части, бактериологическое оружие, санитарно-эпидемиологическая и бактериологическая разведка

### Как устроены вопросы

- В каждом очаге ровно 10 вопросов: 4 **генерируемых** (числа, даты, дозы меняются для каждого участника и каждой попытки) и 6 содержательных.
- Неверные варианты строятся из типичных ошибок (например, OR вместо RR, неверный знаменатель, неверный срок наблюдения) и подбираются близкими по длине и формулировке, чтобы правильный ответ не выделялся.
- Порядок вариантов случайный.

## Быстрый старт

### Локально

1. Скачайте файл `epidemiologik_praktikum.html`.
2. Откройте его в любом современном браузере (Chrome, Edge, Firefox, Safari).

Никакой установки, сборки или сервера не требуется.

### GitHub Pages

1. Переименуйте файл в `index.html` и положите в корень репозитория.
2. **Settings → Pages → Build and deployment**: Source — *Deploy from a branch*, Branch — `main` / `(root)`.
3. Через минуту страница будет доступна по адресу `https://<ваш-аккаунт>.github.io/<репозиторий>/`.

## Технологии

- Чистые HTML, CSS и JavaScript (один файл, ~1 МБ не превышается).
- Данные и прогресс хранятся в `localStorage` браузера, поэтому прогресс сохраняется между сессиями на одном устройстве.
- Библиотек и CDN нет.

## Отчёты и хранение результатов

- **Личный отчёт** (вкладка *Hisobot*) работает везде: история попыток, сводка, экспорт в CSV.
- **Общий отчёт всех участников** (кнопка «Barcha ishtirokchilar») использует общее хранилище среды Claude Artifacts и работает **только** при публикации страницы там. На GitHub Pages эта функция недоступна: преподавателю нужно собирать CSV-файлы участников вручную или подключить собственный бэкенд (например, Google Sheets, Firebase, Supabase) в функции `syncRemote()`.

## Источники и важное предупреждение

Материал составлен на основе:

- календарно-тематического плана кафедры эпидемиологии на 2026–2027 учебный год (темы и последовательность занятий);
- Национального календаря профилактических прививок Республики Узбекистан (данные gov.uz).

> ⚠️ **Учебный проект.** Инкубационные периоды, сроки наблюдения за контактными, схемы постэкспозиционной профилактики (в т. ч. при бешенстве, ВИЧ, менингококковой инфекции), режимы стерилизации и дозировки в задачах — учебные модели, основанные на общепринятых нормах. **Перед практическим применением сверяйте их с действующими нормативными документами Министерства здравоохранения Республики Узбекистан.** Проект не является медицинским руководством.

Национальный календарь прививок может изменяться (например, схема вакцинации против ВПЧ пересматривается) — при изменении календаря нужно обновить соответствующие вопросы.

## Структура файла

```
epidemiologik_praktikum.html
├── <style>            — оформление (тёмная тема, адаптивная вёрстка)
├── <nav> и <section>  — вкладки: Boshlash, Vazifalar, Kasallik o'chog'i,
│                        Vaziyatli masalalar, AI-yordamchi, Hisobot, Lug'at
└── <script>
    ├── TASK_DEFS          — генераторы расчётных задач
    ├── OB_SCENARIOS       — сценарии очагов
    ├── OB_GROUPS          — группировка очагов по занятиям
    ├── g_* (генераторы)   — параметризованные вопросы (RR, OR, VE, PPV, даты, дозы …)
    ├── ST_TOPICS          — блоки «Vaziyatli masalalar» (в т. ч. Национальный календарь)
    └── recordResult / renderReport — результаты и отчёты
```

## Как добавить свой очаг или вопросы

1. Добавьте объект сценария в `OB_SCENARIOS` (поля: `id`, `icon`, `title`, `subtitle`, `diagnosis`, `curve`, `cases`, `lab`, `control`, `final`, `questions`).
2. Для вопроса используйте `Q(текст, верный, неверный1, неверный2, неверный3, пояснение)` или готовые генераторы `g_rr`, `g_or`, `g_ve`, `g_obs`, `g_win`, `g_ppv` и др.
3. Включите `id` очага в нужную группу в `OB_GROUPS`.
4. Проверьте, что в очаге ровно 10 вопросов и у каждого 4 уникальных варианта.
